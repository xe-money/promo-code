# XE Promo Code 2027 – GitHub Pages Repository

Static, responsive website based on the supplied XE referral guide.

## Publish on GitHub

1. Create a **public** repository named `promo-code`.
2. Upload all files from this ZIP into the repository **root** (not into a nested folder).
3. Open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, and save.
4. Your website will normally be `https://xe-money.github.io/promo-code/`.
5. Canonical URL, Open Graph URL, sitemap.xml and robots.txt are already configured for https://xe-money.github.io/promo-code/

## Contents
- `index.html`: full 2027 guide and multilingual content
- `style.css`: mobile-friendly design
- `script.js`: referral-code copy button
- `CONTENT.md`: editable Markdown content
- `robots.txt`, `sitemap.xml`: crawler files
- `.nojekyll`: publish static files without Jekyll processing
